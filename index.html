Podio MCP Server

Connect Podio to Cursor, Claude, and other AI tools

Model Context Protocol

What is this?

A Model Context Protocol (MCP) server that exposes Podio to AI assistants. Use it from Cursor, Claude Desktop, or any MCP-compatible client to query apps, manage items and tasks, search, and call the Podio API—all from natural language.

  • Items: get, create, update, delete, filter
  • Apps & spaces: list, get, create
  • Tasks: list, create, complete
  • Comments, files, hooks, search, metadata

Add to your AI tool

You can connect in two ways: local (run the server on your machine) or remote (connect to a URL, e.g. Docker).

Option A – Local (Cursor with path)

Cursor runs the server in your project. Add this to .cursor/mcp.json (or your IDE’s MCP config):

{
  "mcpServers": {
    "podio-developer-mcp": {
      "command": "node",
      "args": ["/absolute/path/to/podio_mcp_server/dist/index.js"]
    }
  }
}

Replace /absolute/path/to/podio_mcp_server with your project path. Then create podio.config.json in the project root (copy from podio.config.json.example) and add your Podio credentials.

Option B – Remote (URL / Docker)

Connect to a server running over HTTP (e.g. at https://podiomcp.example.com). Add this to your MCP config:

{
  "mcpServers": {
    "podio-developer-mcp": {
      "url": "https://podiomcp.example.com/sse"
    }
  }
}

After connecting, call the setPodioConfig tool (podio_system, operation set_config) once with your clientId, clientSecret, and apps. No config file on the server.

Setup steps (Cursor, local)

  1. Clone and build

    git clone <repo> && cd podio_mcp_server && npm install && npm run build

  2. Create config

    In the project root, create podio.config.json (e.g. copy from podio.config.json.example). Add your Podio clientId, clientSecret, and apps (name, appId, appToken from Podio Developer settings).

  3. Add MCP server

    In Cursor: open .cursor/mcp.json and add the podio-developer-mcp entry with command and args pointing to dist/index.js (see Option A above). Use the absolute path to your project.

  4. Restart Cursor

    Restart Cursor so it starts the MCP server. Use the ping or get_config_status tool to verify.

Config file (local only)

For local use, the server reads podio.config.json from the project root. It does not create this file; you must create it.

{
  "clientId": "your-client-id",
  "clientSecret": "your-client-secret",
  "username": "your-username",
  "password": "your-password",
  "apps": [
    { "name": "Projects", "appId": 12345, "appToken": "your-app-token" }
  ]
}

Get clientId and clientSecret from Podio → Settings → Developer → API. Get appId and appToken from each app’s Developer section.
